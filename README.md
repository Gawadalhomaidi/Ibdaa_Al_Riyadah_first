## 🚀 حول نظام Ibdaa Al Riyadah ERP

نظام **Ibdaa Al Riyadah ERP** هو نظام متكامل متطور لإدارة موارد المؤسسات، مبني باستخدام أحدث تقنيات Laravel 10. تم تصميمه خصيصاً لتلبية احتياجات الشركات العربية مع واجهة مستخدم عربية بديهية وتجربة مستخدم متميزة.
*

## 🛠️ التقنيات المستخدمة

### Backend التقنيات الخلفية
- **Laravel 10** - إطار العمل الرئيسي
- **PHP 8.1+** - لغة البرمجة الخلفية
- **MySQL 8.0** - قاعدة البيانات الرئيسية
- **Eloquent ORM** - نماذج البيانات المتقدمة

### Frontend التقنيات الأمامية
- **Tailwind CSS** - إطار التصميم المتجاوب
- **Alpine.js** - التفاعلات الديناميكية
- **Chart.js** - الرسوم البيانية التفاعلية
- **Font Awesome 6** - مكتبة الأيقونات

### أدوات التطوير والبناء
- **Composer** - إدارة حزم PHP
- **NPM** - إدارة حزم JavaScript
- **Vite** - بناء وتجميع الـ Assets
- **Git** - نظام التحكم بالإصدارات
